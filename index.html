Featured project

Movies Store

A full-stack Django web application that lets users browse a movie catalog, search titles, manage a shopping cart, place orders, and read or write reviews — with a full admin dashboard for managing users, movies, reviews, and orders.

Built as a course project following Django 5 for the Impatient step-by-step, then deployed live on PythonAnywhere. The project was developed iteratively over several recorded work sessions covering design, coding, debugging, and deployment.

Django Python SQLite Bootstrap PythonAnywhere
Live demo Demo video

What it does

  • Account registration & login for personalized access
  • Browse, search, and view details for the movie catalog
  • Shopping cart: add items, clear cart, and checkout
  • Order history so users can track past purchases
  • Create, edit, delete, and report movie reviews
  • Admin tools to manage users, movies, reviews, and orders
  • Responsive UI usable on any desktop browser

Process

Development followed the textbook's chapter progression — models and the admin site first, then views, templates, authentication, cart/order logic, and reviews — with each stage tested locally before deploying updates to PythonAnywhere. Work was logged across multiple recorded sessions covering design decisions, debugging, and deployment steps.
